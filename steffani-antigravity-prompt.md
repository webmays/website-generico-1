# PROJETO STEFFANI — INSTRUÇÃO INICIAL

Prepare e organize completamente o projeto antes de iniciar a implementação visual.

## CONTEXTO

Projeto: website profissional da Steffani.

Área: estética, procedimentos, cursos, marca pessoal.

Objetivos principais:

- vender procedimentos;
- vender cursos;
- transmitir autoridade;
- transmitir sofisticação;
- gerar desejo;
- facilitar navegação;
- conduzir o visitante para contato/agendamento/compra sem parecer uma landing page agressiva.

Conceitos principais:

- sofisticado;
- estratégico;
- intuitivo;
- minimalista;
- editorial;
- moderno;
- premium;
- feminino adulto;
- autoridade;
- fácil acesso.

Evitar:

- estética infantil;
- rosa excessivo;
- "menininha";
- template SaaS;
- landing page genérica;
- cara de site feito por IA;
- cards excessivos;
- glassmorphism;
- gradientes aleatórios;
- blobs decorativos;
- rounded corners em tudo;
- excesso de ícones;
- luxo preto+dourado genérico.

A sofisticação deve vir de composição, fotografia, tipografia, alinhamento, espaço, contraste e ritmo visual.

# GIT — REGRA PERMANENTE

A partir deste momento, Git faz parte do fluxo padrão.

Após finalizar qualquer processamento significativo:

1. revisar mudanças;
2. `git status`;
3. adicionar arquivos relevantes;
4. criar commit;
5. realizar push sempre que possível.

Fluxo:

```text
analisar
planejar
implementar
validar
corrigir
commit
push
resumir
```

Commits pequenos, claros, rastreáveis.

Exemplos:

```text
chore: estrutura inicial
docs: planejamento inicial
design: sistema visual base
feat: hero
feat: navegação serviços
feat: seção procedimentos
feat: seção cursos
fix: responsividade mobile

perf: otimização imagens
```

Não acumular quantidade enorme de mudanças antes de commitar.

Não criar commit vazio.

Não commitar arquivos temporários.
